n# Cubegle Hero Redesign - Premium Interactive AI Experience

## Mission

Transform the current Cubegle Hero section into a premium interactive experience that feels comparable to the quality of Stripe, Linear, Vercel, OpenAI, Apple, Framer, Arc Browser, and Notion AI.

This is NOT a typical IT services landing page.

The Hero should feel like an interactive AI product.

Visitors should immediately understand that Cubegle builds modern Enterprise Data, AI, Cloud, and Analytics platforms.

The experience should create a memorable first impression while remaining elegant, fast, accessible, and production-ready.

# IMPORTANT

Before writing ANY code:

1. Analyze the existing Hero implementation.
2. Preserve the current branding.
3. Reuse existing components whenever possible.
4. Review the existing mascot implementation.
5. Build incrementally.
6. Keep the code clean and maintainable.
7. Never rewrite components unnecessarily.

# CRITICAL REQUIREMENT

## Preserve the Existing Mascot

The existing mascot is part of Cubegle's brand identity.

DO NOT redesign it.

DO NOT replace it.

DO NOT regenerate a different-looking character.

DO NOT change:

- Face
- Eyes
- Hair
- Smile
- Outfit
- Colors
- Body proportions
- Accessories
- Illustration style
- Line thickness
- Brand personality

The mascot must remain identical throughout all animations.

It should always look like the same Cubey.

Only animate the existing mascot.

Use rigging / skeletal animation principles whenever possible.

Every pose should be derived from the existing mascot.

Never create multiple inconsistent versions.

Treat Cubey as a reusable character asset.

Future animations must always reuse this exact mascot.
